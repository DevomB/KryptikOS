# its reason: `FINDING PATH # why`, or `RPATH PATH RPATH # why`, since an RPATH
# entry accepts one rpath. PATH and RPATH are globs on the object's path in the
# image and on its rpath. A finding not listed here fails --strict, and so does
# an entry that no longer matches anything.
